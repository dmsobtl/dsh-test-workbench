# Skill: 登录功能测试

## 触发条件

当用户要求测试登录功能、登录页面、认证流程时使用。

## 前置检查

1. 确认目标 URL 可达
2. 如果是预发环境，提醒用户确认环境切换

## 测试步骤

### 正向流程

1. `app_launch` 打开登录页面
2. `app_accessibility` 获取页面结构，确认表单元素
3. `app_verify` 验证以下元素存在且可见：
   - 用户名/手机号输入框
   - 密码输入框
   - 登录按钮
4. `app_type` 输入正确的测试账号凭据
5. `app_click` 点击登录按钮
6. 等待页面跳转
7. `app_verify` 验证跳转到预期页面（dashboard/首页）
8. `app_screenshot` 保存登录成功状态截图

### 反向流程

1. 返回登录页
2. 输入错误密码
3. 点击登录
4. `app_verify` 验证错误提示出现且文案正确
5. 验证页面未跳转

### 边界场景

- 空用户名提交 → 验证字段校验提示
- 空密码提交 → 验证字段校验提示
- 超长输入 → 验证无异常

## 产出

- 每个步骤的 pass/fail 结果
- 关键状态截图
- 结构化测试报告
